## radioegor146/native-obfuscator

- ASM preprocessing rewrites dynamic invocation and some method-handle constants before instruction handlers emit per-class C++ and a CMake project. The direct `invokedynamic` handler rejects any surviving instruction. The LDC preprocessor handles method-handle and method-type constants, and the LDC emitter rejects an unsupported constant type. Converted output is set to major version 52, despite the build declaring ASM 9.8. Parser capability therefore does not establish safe preservation of contemporary class-file features. [Preprocessors](https://github.com/radioegor146/native-obfuscator/blob/b3b3a40ac27c78e343631b078fa62f932edd09ff/obfuscator/src/main/java/by/radioegor146/bytecode/PreprocessorRunner.java#L10-L23) · [LDC preprocessing](https://github.com/radioegor146/native-obfuscator/blob/b3b3a40ac27c78e343631b078fa62f932edd09ff/obfuscator/src/main/java/by/radioegor146/bytecode/LdcPreprocessor.java#L12-L36) · [Class rewrite](https://github.com/radioegor146/native-obfuscator/blob/b3b3a40ac27c78e343631b078fa62f932edd09ff/obfuscator/src/main/java/by/radioegor146/NativeObfuscator.java#L274-L297)
- `JNI_OnLoad` installs a loader method that dispatches registration by class ID. Generated per-class registration tables use method names and descriptors, but the emitter clears pending registration exceptions and the loader template returns a successful JNI version without checking the final registration result. The unpacking loader selects a resource and copies it to a temporary file before loading it. [Registration template](https://github.com/radioegor146/native-obfuscator/blob/b3b3a40ac27c78e343631b078fa62f932edd09ff/obfuscator/src/main/resources/sources/native_jvm_output.cpp#L11-L43) · [Class registration](https://github.com/radioegor146/native-obfuscator/blob/b3b3a40ac27c78e343631b078fa62f932edd09ff/obfuscator/src/main/java/by/radioegor146/source/ClassSourceBuilder.java#L94-L129) · [Loader](https://github.com/radioegor146/native-obfuscator/blob/b3b3a40ac27c78e343631b078fa62f932edd09ff/obfuscator/src/main/java/by/radioegor146/compiletime/LoaderUnpack.java#L12-L92)
- The differential harness compiles fixtures, builds C++ with CMake, checks subprocess results, and compares stdout. The workflow declares JDK 8, 11, 17, 21, and 25 across Ubuntu, macOS, and Windows with some platform exclusions. Its snippets check integer division by zero and minimum divided by minus one, but integer addition directly uses signed C++ operands without enforcing Java wraparound in the expression. Use the harness structure and arithmetic cases to design independent tests. [Harness](https://github.com/radioegor146/native-obfuscator/blob/b3b3a40ac27c78e343631b078fa62f932edd09ff/obfuscator/src/test/java/by/radioegor146/ClassicTest.java#L132-L188) · [CI](https://github.com/radioegor146/native-obfuscator/blob/b3b3a40ac27c78e343631b078fa62f932edd09ff/.github/workflows/main.yml) · [Arithmetic snippets](https://github.com/radioegor146/native-obfuscator/blob/b3b3a40ac27c78e343631b078fa62f932edd09ff/obfuscator/src/main/resources/sources/cppsnippets.properties#L118-L139)

## Open-MyJ2c

- Emits C11, uses Zig 0.10.0 with a Windows/Linux/macOS x64 and ARM64 target table, and packs libraries into a data resource. The setup path downloads Zig when needed. The translator injects a per-class native bootstrap, uses exported JNI registration entry points, and forces converted classes to major 52. The compiler reads a binary loader resource, supports supplying a library URL, and has licensing modes that conditionally generate time-dependent registration. Prefer an explicit local compiler path and a source-built offline loader. [Class rewrite](https://github.com/MyJ2c/Open-MyJ2c/blob/814dd48ea6cc0b7e6b5663d8cc8f1b50684739fe/myj2c/src/main/java/cn/muyang/MYObfuscator.java#L311-L320) · [Target and compiler selection](https://github.com/MyJ2c/Open-MyJ2c/blob/814dd48ea6cc0b7e6b5663d8cc8f1b50684739fe/myj2c/src/main/java/cn/muyang/MYObfuscator.java#L441-L529) · [Loader packaging](https://github.com/MyJ2c/Open-MyJ2c/blob/814dd48ea6cc0b7e6b5663d8cc8f1b50684739fe/myj2c/src/main/java/cn/muyang/MYObfuscator.java#L595-L655) · [Registration](https://github.com/MyJ2c/Open-MyJ2c/blob/814dd48ea6cc0b7e6b5663d8cc8f1b50684739fe/myj2c/src/main/java/cn/muyang/MYObfuscator.java#L1245-L1258)
- ASM 9.4 is declared. The dynamic-invocation handler reconstructs selected Java bootstrap arguments through JNI and rejects other types. The active integer division templates use raw signed C division without Java's zero and overflow cases. The differential test uses a Windows target and compares stdout with separate fallback handling. The checks for successful reference and protected Java subprocess exit are commented out. The CLI fingerprints hardware and performs remote license and update queries. Reject these components as foundations. [Build](https://github.com/MyJ2c/Open-MyJ2c/blob/814dd48ea6cc0b7e6b5663d8cc8f1b50684739fe/myj2c/build.gradle#L29-L37) · [Bootstrap handler](https://github.com/MyJ2c/Open-MyJ2c/blob/814dd48ea6cc0b7e6b5663d8cc8f1b50684739fe/myj2c/src/main/java/cn/muyang/instructions/InvokeDynamicHandler.java#L99-L133) · [C snippets](https://github.com/MyJ2c/Open-MyJ2c/blob/814dd48ea6cc0b7e6b5663d8cc8f1b50684739fe/myj2c/src/main/java/cn/muyang/utils/Snippets.java#L174-L189) · [Harness](https://github.com/MyJ2c/Open-MyJ2c/blob/814dd48ea6cc0b7e6b5663d8cc8f1b50684739fe/myj2c/src/test/java/cn/muyang/ClassicTest.java#L109-L174) · [CLI](https://github.com/MyJ2c/Open-MyJ2c/blob/814dd48ea6cc0b7e6b5663d8cc8f1b50684739fe/myj2c/src/main/java/cn/muyang/Main.java#L175-L282)

## masxinlingvonta

- Analyzes bytecode into basic blocks and emits LLVM IR directly through JavaCPP's LLVM 11 bindings. Its optimizer runs the LLVM standard module pipeline. The translator creates JNI-mangled LLVM functions. Loader injection is tied to a Java main method, and the loader tests for a 64-bit-looking architecture string rather than distinguishing x64 from ARM64. A runnable branch-test fixture loads a named library. ## nuym/j2c

- Uses ASM 9.4, rewrites converted classes to major 52, packages native artifacts in a compressed data resource, and uses Zig 0.9.1 with OS/architecture targets. C generation includes per-class JNI registration symbols and reconstructs dynamic invocations with JNI. Unsupported LDC constants throw. Its integer division snippets have the same missing Java arithmetic guards as Open-MyJ2c. A loader Gradle test dependency is declared, but this checkout contains no `src/test` fixture and the README reports a small external benchmark without a reproducible runtime matrix. ## Implications for implementation

- Preserve the class-file version and metadata. Keep constructors, initializers, and transformation-sensitive Fabric classes in Java until handling is proven. Report unrecognized instructions and linkage constructs at method granularity. Use a JVM-side helper only after its class ownership, lazy linkage, exception behavior, and bootstrap identity work in differential tests.
- Make native arithmetic semantics explicit. Test all four integer operations that expose overflow or division traps, negative and oversize shifts, signed zero, floating conversion bounds, exception messages and types, and linkage from concurrent callers.
- Use narrow, source-built registration and loading. Check `JNI_OnLoad` and registration results, use class identity supplied by the relevant loader, and test a corrupted or mismatched artifact. Measure subprocess exit, observable behavior, size, and timing separately. Compiling a target establishes artifact generation, while a runner for that target is needed to establish runtime compatibility.
